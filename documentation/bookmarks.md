# Закладки сообщений

В меню сообщения выберите «Добавить в закладки». Повторное действие снимает
закладку. Отметка отображается рядом с сообщением. В меню личного чата и канала
есть фильтр закладок; он применяется совместно с действующими фильтрами региона
и сообщений. Для старых страниц истории используйте загрузку более ранних
сообщений. AEIC-изображения являются отдельными записями и в фильтр сообщений
с закладками не входят.

Общий список открывается из меню экрана каналов. Он хранит копию текста,
источника, отправителя, перевода при наличии и времени сообщения. Удаление
исходного сообщения или очистка его истории эту копию не удаляет. Закладки
принадлежат выбранной ноде. Идентификаторы сообщений дополнительных ключей
сохраняют получателя, поэтому одинаковые номера строк разных ключей не
совпадают. Связанные ключи контакта и прежние идентичности канала учитываются
при отображении отметки и снятии закладки.

В экране экспорта есть Markdown-экспорт закладок: контакты и каналы
группируются отдельно, сообщения каждой группы идут по времени. Экспорт
включает ссылки и поддерживаемые URL изображений. Сам список не включает
закрытые ключи.

В резервном копировании выберите «Закладки» явно: по умолчанию этот новый
пункт выключен. Формат MeshCore Open v1 использует
`sections.discoveredContacts.preferences.message_bookmarks_<scope>` со списком
снимков. Импорт показывает добавляемые записи перед подтверждением, сохраняет
существующие закладки и проверяет выбранную ноду перед записью. Отмена ничего
не меняет. Повреждение этой секции не блокирует другие читаемые разделы.
Экспорт в формат официального приложения MeshCore закладки не включает.

На native-платформах каждый снимок — отдельная строка таблицы
`message_bookmarks` существующей SQLite-базы истории, с ключом ноды и
идентификатором закладки; индекс по времени ускоряет чтение. Сериализация и
данные исходных сообщений не меняются. Web использует preferences. Переключение
ноды не переносит её закладки в другую область. Очистка демонстрационного
режима удаляет также его закладки.
