# MCOtxt в браузере

Автономный кодек находится в [docs/mcotxt/assets/mcotxt.js](../docs/mcotxt/assets/mcotxt.js),
демонстрация — [docs/mcotxt/index.html](../docs/mcotxt/index.html).
Откройте страницу с диска: сервер, npm и подключение к интернету не нужны.
Интерфейс страницы — на английском языке.
В приложение Flutter эти файлы не добавляются как runtime-зависимость.

1. Введите текст и выберите языки для основной пары, по умолчанию ru/en.
2. Оставьте имя отправителя пустым для сравнения без имени. Для чистого
   текстового измерения смотрите размер frame, отдельно от всего контейнера.
3. При необходимости укажите имя и время цитаты, а также timestamp сообщения.
4. Выберите binary или Base91 и нажмите «Encode».
5. Перенесите результат в декодер или получите `mct:` / бинарный envelope.

`encodedBytes` — размер возвращённых данных; `textEncodedBytes` — размер
frame текста без метаданных и Base91. Проценты считаются относительно UTF-8
исходного текста, отрицательные значения означают увеличение размера.
Пустой текст имеет процент `null`.

Бинарные результаты представлены `Uint8Array`; на странице показан их Hex.
Сам `encode` не добавляет транспортный envelope. Декодер поддерживает тело,
frame, открытый MCO envelope и `mct:`; сырой зашифрованный радиопакет MeshCore
ему передавать нельзя. Список кандидатов кодирования не ограничивает языки,
которые декодер способен прочитать.

[Полный API, примеры подключения и команды проверок](../docs/mcotxt/README.md).
Совместимость проверяется по буквальному снимку рабочего Dart-кодека;
после добавления JS итоговые автоматические проверки и проверка браузера
ожидают подтверждения владельца.
