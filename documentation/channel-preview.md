# Имя отправителя в превью канала

В **Настройки модификации → Визуал**, сразу после «Скрыть индекс канала»,
находится переключатель **«Отображать имя отправителя в превью канала»**.
Он включён по умолчанию, в том числе при обновлении приложения.

При включении текстовое превью последнего сообщения имеет вид
`senderName: доброе утро`. При выключении отображается только `доброе утро`.
Выбор сохраняется после перезапуска приложения.

Имя берётся из самого сообщения, включая сообщения из общей истории.
Для пустого канала сохраняется описание канала. Если сообщение скрыто правилами
блокировки, в превью остаётся общая заглушка без имени отправителя.
