MCOtxt_model_trainer_with_diagnostics.py — обучает модель языка и генерирует .dart, .h, report/debug JSON. Пример:
python MCOtxt_model_trainer_with_diagnostics.py --lang ru --train corpus_ru.txt --debug-json
Готовая Dart-модель автоматически копируется в lib/MCOtxt/models/generated/v1/.

MCOtxt_ab_benchmark.py — проверяет сжатие смешанного текста парой моделей, например RU+EN:
python MCOtxt_ab_benchmark.py --model-a generated/ru/model_ru_debug.json --model-b generated/en/model_en_debug.json --input corpus.txt

verify_runtime_models.py — проверяет manifest, Dart/C-модели, их wire-hash и placeholders:
python verify_runtime_models.py

freeze_model_manifest.py — окончательно замораживает набор моделей MCOtxt v1, запрещая их незаметную замену другими таблицами:
python freeze_model_manifest.py
Запускать только после обучения всех языков v1; пока есть unavailable-модели, freeze будет отклонён.
